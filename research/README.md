# SeedArc 研究归档

目标是让每个探索结论都能追溯到问题、实现、配置、数据与实际运行证据，为未来复现和论文写作积累材料。当前只有目录规范和模板，**没有实验结果，也尚未证明独创性**。

## 目录与归档单位

| 位置 | 内容 |
| --- | --- |
| [ideas/](ideas/README.md) | 研究问题、假设、相关工作、未采纳方案和下一步 |
| [datasets/](datasets/README.md) | 数据集来源、许可、版本、文件清单与哈希，不默认包含原始数据 |
| [configs/](configs/README.md) | 可复用实验配置，保存每次运行实际生效的配置快照 |
| experiments/&lt;run-id&gt;/ | 一次运行的 record.md、配置快照、原始指标、必要日志和代码差异 |
| [results/](results/README.md) | 引用 run ID 的基准汇总、图表、统计与结论 |
| [scripts/](scripts/README.md) | 数据准备、指标处理、统计与绘图脚本及依赖说明 |
| [templates/experiment.md](templates/experiment.md) | 每次实验的记录模板 |

`run-id` 使用 `YYYYMMDD-<topic>-<agent>-<sequence>`，例如 `20261111-store-baseline-agent-a-001`（仅命名示例，并非已运行实验）。创建前确认不重名；每位 Agent 使用独立目录，不覆盖已有运行。

## 最小研究流程（所有参与 Agent）

1. 在根 STATUS.md 领取任务、确认写入范围；阅读相关安全、确定性和测试规范。
2. 先在 ideas 中写问题和可证伪假设、对照、指标与预算，再准备数据集清单、配置和实验 record.md。无源码时只能记为计划。
3. 运行时保留完整命令、实际生效参数、环境、退出状态和原始指标。记录超时、失败、取消、无收益，不得删去不利结果。
4. 分析脚本从原始数据生成汇总，结果报告引用 run ID、配置和脚本版本。原始结果保留，纠错以新运行或显式更正说明处理。
5. 更新 STATUS.md：执行者报告、协调者独立验证、未验证事项分别写清。无研究内容的常规小改动不强制创建实验。

## 必需证据

- **问题与方法**：研究假设、相关工作链接 / 书目信息、比较方法、预先确定的指标、预算及停止条件；探索性分析单独标记。
- **代码**：Git commit、dirty 状态、相关 patch 和未跟踪源码快照；若尚无首个提交，保存运行所需源码 / 脚本快照及 SHA256，不能只写“当前代码”。快照不得含密钥或受限数据。
- **环境**：OS、CPU / RAM、编译器、Release 参数、依赖版本、线程和硬件设置；运行日期带时区。没有测量的字段写未测量，不能填 0。
- **输入**：数据集 ID / 版本、来源与获取日期、许可 / 再分发条件、选择规则、预处理、相对文件清单、每文件大小及 SHA256；训练 / 调参 / 评估划分及其依据。
- **配置**：实际命令、全部生效参数、种子、格式 / 策略版本、算法等级、分块、字典、线程、时间 / 次数 / 内存预算。
- **原始指标**：每次重复运行的完整归档字节数、编码 / 搜索 / 解码耗时及计量口径、峰值内存及测量方法、候选数、退出码、逐字节往返 / 哈希验证；原始数据优先 JSON / JSONL 等机器可读格式，不能只存截图或均值。
- **分析**：重复次数、运行顺序、预热 / 缓存策略、波动和异常值处理，完整脚本调用与依赖；结论适用范围、反例和下一步。

公平比较相同输入、可比计算 / 时间预算；统计完整归档开销，包括索引、种子、字典和元数据。性能只使用 Release。普通 checksum 不替代逐字节恢复验证，不当作认证加密。

## 证据与公开边界

猜想、自己的实测结果、第三方报告、独立复现分别标注。论文相关工作必须有可核查引用；未检索不能宣称首次提出，负面结果同样归档。调参集与最终评估集的重复使用要明确披露。

小型配置、清单、原始指标、必要日志、报告、脚本应纳入版本管理。大型数据、压缩产物和临时文件放入本目录下被忽略的 `local/`；记录可恢复位置、大小和哈希，忽略不代表备份，不自动删除唯一实验原件。可公开的小型固定样例按需放入具体实验目录。

不把私有数据、受限数据、令牌、签名下载地址和机器凭据写入可提交文件。不可再分发的数据只记获准公开的元信息与获取步骤；项目 GPL 声明不改变数据集自身许可。若限制使复现受阻，如实说明。

正式协议决策仍放 docs/decisions，不由研究报告静默冻结。STATUS.md 只存当前任务摘要，长期路线仍在 docs/development-plan.md。
