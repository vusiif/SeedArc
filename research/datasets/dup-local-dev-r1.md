# dup-local-dev-r1

2026-11-27，DEV-036。**本机专用的 dev 数据集，保留自然存在的重复文件；不是留出集。** 建库和检查入口是 [dup_local_corpus.py](../scripts/dup_local_corpus.py)，机器可读信息在 [metadata.json](dup-local-dev-r1/metadata.json)。

**为什么要建**：DEV-023 的两棵树来自 [append-linux-large-dev-r2](append-linux-large-dev-r2.md)，那里"每个内容 SHA256 仅保留一个路径"，所以测不出重复有多常见。来源由用户 2026-11-27 选定（Cargo + rustup + npm）。

"候选"指过滤之后、按组抽取之前的全部文件；它的重复率比样本的重复率更能代表这类目录本身。

## 规则（在任何压缩测量之前固定）

- 只收普通文件，不跟随符号链接和目录联接；大小 1 B – 32 MiB；不收已压缩的格式（`.gz`、`.zip`、`.crate`、`.png` 等，完整列表见 metadata）。
- **与留出集不相交**：内容 SHA256 出现在任何留出或测试清单中的文件一律排除，这些清单是 append-r1 holdout、g5-holdout-r1、b2r5-corpus-r1/r2 test。共排除 7 个，都在 cargo。`--check` 会重新核对，结果是共享内容 0。
- **不用的来源**：MSYS2、Python、vcpkg、Windows Kits。已有的留出集（append-r1 native-bin、g5）就取自这些安装目录，即使按哈希排除，内容仍然相关。
- **抽取**：每个池按 `sha256("dup-local-dev-r1:<组>")` 排序，整组取用，池上限 256 MiB；放不下的组跳过。
- **路径**：
  - 逐条用 `seedarc_path_check` 检查（ADR-0005），cargo 被拒 221 条；
  - 再做 `casefold()` 冲突过滤，排除 0 条；
  - 整个数据集通过生产清单检查（`--manifest`），共 18 984 个条目，含隐含的父目录。

## 限制

- **只在本机评估**：内容不上传、不再分发；仓库里只有相对路径、大小、SHA256 和组。清单里的路径会显示本机装过哪些 crate、工具链和 npm 包。
- **rustup 偏大文件**：样本只有 283 个文件。`lib/rustlib/src`、`share/doc/rust/html` 等大组超过上限被跳过，所以样本里大多是大二进制，候选全体里的小文档和源码重复没有进入样本。
- **重复率依赖本机的使用历史**：cargo 缓存了哪些版本、装过几个工具链，都影响结果。只代表"开发者机器上的包缓存 / 工具链目录"这一类数据，不代表一般文档或媒体目录。
- 被路径检查拒绝的 221 条只记了数量，没有逐条记录原因。
