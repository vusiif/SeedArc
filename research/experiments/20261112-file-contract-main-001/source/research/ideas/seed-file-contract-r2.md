# B2-r2：路径身份与叠加行为

日期：2026-11-12。研究控制层候选，未冻结 Seed 或归档协议。输入：[评估建议](../../docs/review_results/SeedArc_B2文件级覆盖颗粒度评估与r2验收建议.md)。

## 行为边界

新增 catalog-r1 路径适配层，保留 overlay-r1、A/B-r1 及其历史输出。`make_path_file_plans` 接受完整文件清单（含空文件）、块清单及路径覆盖；清单含本次 `file_id` 与归档内相对路径。路径不是清单下标，ID 可随调用改变，只要块归属同步。

复用 `validate_manifest_paths` 的现有 Windows 路径规则：有效 UTF-8、已是 NFC、`/` 分隔，拒绝反斜线、危险组件、重复路径、大小写冲突及文件充当目录。**不自动改写路径或进行大小写折叠**；覆盖键必须与清单路径逐字节相同。仅大小写不同的覆盖也不匹配。组合字符与预组合字符不自动等价转换，非 NFC 清单被拒绝。非 Windows 沿用原校验器明确拒绝。

插入 / 删除其他文件、改变顺序或本次 file_id，不会把覆盖迁移到不同路径。目标删除 / 重命名导致旧键 `invalid_argument`，整次计划失败；调用者显式移除或重新绑定后再生成。没有自动重命名识别、内容哈希身份、跨分块稳定标识或持久覆盖存储。

**身份匹配与策略分配不同**：B-r1 仍以 `global_block_id` 决定 Codec。插入文件若重排全局编号，Codec 允许随之变化；路径匹配保证覆盖对象正确，不保证原文件 Codec 不变。测试分别覆盖保留 global ID 与重新编号。

## 合并与无变化

调用方提供当前全局 B 字段，再按文件逐字段覆盖；文件覆盖优先，未覆盖字段继承。清除通过移除字段 / 条目并重新生成，不保留旧计划快照。典型 Zstd 等级序列 `3 → 4 → 6 → 4`。本轮只调整等级，Codec seed 保持0，不引入 Codec 强制选择或重采样。

完整文件清单使空文件成为已知文件：合法覆盖允许但没有块变化。已知文件不含目标 Codec 同样成功且变化集合为空；结果摘要明确说明该事实。非法等级、重复覆盖即使对应空文件也拒绝。重复 ID、未知块归属、未知路径、空覆盖均拒绝。未知 catalog 修订返回 `unsupported_feature`；路径规则错误沿用 `unsafe_path`。

## 限额与验证

最多4096文件、4096覆盖、65536块。路径各最多4096字节，清单路径加每条32字节记账最多16MiB，复制前检查；其余路径深度 / 组件与冲突限额沿用现有校验器。输出继续按原 global ID 排序；不生成文件或块编号。使用 map / set 有界查找，避免块数乘覆盖数扫描。

独立研究工具 `seedarc_seed_scope_contract --observe` 输出固定身份扰动、叠加和规模夹具及原始计划；不读取实际文件。新观察归档在 [20261112-file-contract-main-001](../experiments/20261112-file-contract-main-001/record.md)。生成开销与峰值内存未构成性能验收；本轮无需新增异步 / 取消框架。

后续真实压缩实验仍需完整归档字节、往返、预算与时间 / 内存证据，拟议计划不能证明压缩收益。文件级控制如何编码进 Seed 仍未决定。
