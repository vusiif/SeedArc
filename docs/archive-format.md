# SeedArc 归档格式与兼容性约束

> **注意：本文件是待定设计要求，不是已经冻结的 `.spk` 字节规范。** 未决定魔数、扩展名、字段布局、编码长度、具体校验算法或资源限额。不能据此编造“现有格式兼容性”。

M1 已实现[实验 ADR-0001](decisions/0001-experimental-container-and-output.md)的头部 / 块范围校验和 Windows 安全写入原语并通过验收；格式仍为 experimental、未冻结。本文维护总体要求，当前进度见 [STATUS.md](../STATUS.md)。

## 1. 目标与原则

SeedArc 归档要能可靠保存文件与目录、压缩块、种子、版本化策略及所有解码必需信息。归档格式直接影响压缩收益、跨版本可解码性与安全边界，须在初版外部使用前写正式规范 / ADR。

- 使用固定宽度字段，明确字节序、长度编码、最大尺寸、偏移和边界。
- 非法 / 未知算法、必需扩展、版本、字典和长度必须明确失败；可跳过的扩展需要标准化规则。
- 字典、编码器参数、块边界、文件索引、文件元数据与校验信息属于归档开销，计入优化目标。
- 种子只能重建**解码器确实可获得**输入条件下的策略；编码时依赖原文作出的决策需额外记录。
- 支持有界流式处理：不依赖整包或整文件驻留 RAM。

## 2. 概念性组成（顺序及编码尚未冻结）

```text
[魔数、容器格式版本、特性 / 必需扩展标记]
[种子模式、种子值或外置种子要求、策略生成器版本]
[编码器登记 / 参数 / 字典描述]
[目录与文件元数据索引]
[块表：文件 / 块关联、偏移、压缩长度、原始长度等]
[可选字典、辅助数据、压缩块]
[完整性校验、可选尾部目录 / 完整性元数据]
```

这是**概念清单**。未经过设计审查、序列化测试、实际开销与解码验证，不得宣称它是 v1 格式、直接对外发包或冻结字段。

## 3. 必须决定的格式契约

| 领域 | 必须在首次公开使用前明确 |
| --- | --- |
| 版本 / 能力 | 魔数、格式版本、必需 / 可选扩展、向后 / 向前兼容的接受策略 |
| 基础编码 | 字节序、无符号 / 有符号数、长度编码、对齐、允许的重复字段和校验覆盖范围 |
| 文件系统 | 路径编码、相对根、排序、大小写 / Unicode 冲突、时间戳 / 权限 / 特殊条目策略 |
| 分块 | 块数、块边界、块与文件映射、索引顺序、空文件 / 目录表示 |
| 算法 | 稳定算法 ID、编码器必需解码参数、LZMA2 流形式、可选字典、字典引用、未知编码器错误 |
| 种子 | 种子编码与模式、生成器版本、策略所依赖可用元数据、外置种子的合法性和错误路径 |
| 资源限制 | 元数据 / 块 / 文件数限额、单块和总输出、最大路径、字典与内存上限 |
| 完整性 | 校验算法、覆盖域、错误 / 截断检测、成功写出与失败清理策略 |

普通 checksum / hash 检测意外损坏，**不能**当作对恶意篡改的密码学认证；加密如未来引入，采用独立且经审查的认证加密设计。

## 4. 解析器的检查顺序

1. 检查输入规模及最小头部，读取受限长度的魔数 / 版本 / 特性位。
2. 检查字段长度、偏移、加法与乘法溢出；不信任任何来自归档的 size。
3. 验证文件条目、块索引及引用的数量 / 一致性；拒绝越界、交叠和不合法关系。
4. 验证编码器 ID、参数、所需字典、解码资源预算以及必要的策略 / 种子条件。
5. 限额流式解压并校验输出字节数和完整性；始终遵守安全输出路径 / 临时写入策略。
6. 只有全部必要检查成功，才对用户报告成功；失败不能留下貌似有效的归档或覆盖已有文件。

数据格式本身不应允许“无限解压”。对超限合法输入，应明确返回资源限制错误；限制可配置与否必须说明，不能自动无限增大。

## 5. 兼容性和决策权限

- 区分**格式可解码兼容**与**编码结果逐字节复现**：受支持的旧格式应由新解码器正确恢复；不同编码器版本不保证产生相同压缩字节。
- 正式发布前确认是否采用 `.spk` 扩展名，避免从历史草案自动推断；任何归档样例必须明确产生它的格式版本、生成器版本及依赖信息。
- 一旦冻结或用于持久用户数据，字段删除、含义变化或放弃旧版解码属于 **C 级必须确认**。
- 对旧版格式保存 golden archives 与坏包样例。格式演进应记录 ADR、迁移策略和兼容性测试；不能用一次批量重打包代替对旧包支持的承诺。
- **发布之前**可以做原型实验，但必须标记 `experimental`，不得暗中把实验产物升级成长期稳定承诺。

## 6. 必须有的最小测试

- 空目录、空文件、单块 / 多块、非常多的小文件、非 ASCII 路径以及高熵数据。
- 截断头 / 块、不合法长度、整数边界、未知版本 / 算法、坏字典、错误种子、重复文件和重叠索引。
- 超大声明输出、过多文件 / 条目、畸形路径、损坏校验、磁盘写入失败与取消。
- 正确归档往返，旧版 golden archives 可解码，以及同条件下的确定性测试。

具体测试层级、工具需求与完成定义见 `testing.md`。
